## 설정 순서 (처음 한 번, 약 15분)

1. **Supabase 프로젝트 만들기**
   supabase.com에 가입하고 New project를 눌러요. 이름은 자유, 지역은 Northeast Asia (Seoul)를 고르세요.

2. **설정 붙여 넣기**
   왼쪽 메뉴 SQL Editor › New query에 `schema.sql` 내용을 통째로 붙여 넣고 Run을 눌러요. "Success"가 나오면 끝이에요.

3. **주소와 키 복사하기**
   Project Settings › API (Data API)에서 두 가지를 복사해요.
   - Project URL (예: `https://abcdefgh.supabase.co`)
   - anon public 키 (긴 문자열)

   service_role 키는 절대 넣지 마세요. anon 키는 사이트에 공개되어도 괜찮은 키예요.

4. **`config.js` 고치기**
   복사한 두 값을 넣어요. 교사 비밀번호는 6886으로 되어 있어요.
   ```js
   SUPABASE_URL: 'https://abcdefgh.supabase.co',
   SUPABASE_ANON_KEY: 'eyJ...',
   CLASS_CODE: 'test',
   TEACHER_PIN: '6886'
   ```

5. **깃허브에 올리기**
   저장소에 이 폴더의 파일을 모두 올려요 (같은 이름은 덮어쓰기). 몇 분 뒤 깃허브 페이지 주소로 열려요.

6. **확인하기**
   교사로 입장해서 관리 탭을 열어요. "Supabase 실시간 연결"이 보이면 성공이에요. 아이패드(또는 컴퓨터 브라우저 창) 두 개로 1모둠, 2모둠에 입장해서 한 판을 끝까지 해 보세요. 교사 화면의 진행 현황, 점수판, 발표 모드에 올라와야 해요. 카드를 보낸 뒤 화면 아래에서 활동지 사진도 한 장 올려 보세요.

## 수업 전 체크

- 연습할 때는 `CLASS_CODE: 'test'`로 하고, 수업 날 `'2-3'`으로 바꿔 올리면 연습 기록과 섞이지 않아요. 연습 기록은 교사 화면 › 관리 › 기록 지우기로 지울 수 있어요.
- Supabase 무료 프로젝트는 오래(약 일주일) 쓰지 않으면 잠시 멈춰요. 수업 전날 사이트에 한 번 들어가 연결을 확인하세요. 멈춰 있으면 Supabase 대시보드에서 Restore를 누르면 돼요.
- `config.js`를 비워 두면 **체험 모드**예요. 같은 컴퓨터, 같은 브라우저의 여러 탭끼리만 기록이 공유돼요. 혼자 미리 해 볼 때 써요.
- 학생 이름은 저장하지 않아요. 저장되는 것은 모둠 번호, 보낸 카드와 이유, 답, 점수, 올린 사진이에요.
- 교사 비밀번호는 학생이 실수로 교사 화면에 들어가지 않게 하는 잠금 장치예요. 강한 보안이 필요하면 Supabase 로그인 기능으로 바꿀 수 있어요.
